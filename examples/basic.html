OpenHermit Basic Example

This page demonstrates OpenHermit's automatic WebMCP injection. Open your browser's DevTools and inspect the form below — you'll see data-mcp-* attributes automatically injected.

Contact Us

What OpenHermit Does:

  • ✅ Detects the form automatically
  • ✅ Injects data-mcp-action="contact_us"
  • ✅ Injects data-mcp-description with a human-readable description
  • ✅ Injects data-mcp-params with field definitions
  • ✅ Tracks AI agent interactions (if agent detected)
  • ✅ Serves WebMCP manifest at /api/manifest

Try It:

  1. Open DevTools (F12 or Cmd+Option+I)
  2. Inspect the form element
  3. Look for data-mcp-* attributes
  4. Check the Console for OpenHermit logs
